## Public Web Routing via SeasonalWeb

SeasonalWeb receives public HTTP/HTTPS traffic and routes hostname-based services to the appropriate internal backend. Cloudflare remains the public DNS and TLS edge for proxied hostnames.

| Hostname | SeasonalWeb backend | Authentication / Exposure | Notes |
|---|---|---|---|
| `grafana.seasonalnet.org` | `http://192.168.1.15:3000` | Public via Cloudflare; Grafana uses Authentik OAuth/OIDC with a local break-glass admin account retained | SeasonalMonitor dashboard front door. Prometheus (`192.168.1.15:9090`) is intentionally not published. |
