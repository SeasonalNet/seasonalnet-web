## Notes and Constraints

- Phone-LAN is a **flat LAN**, not a VLAN-backed fabric. Physical switching is presently unmanaged, so the map records the L3/L2 segment and observed devices rather than a port-by-port switch topology.
- SeasonalPBX replaces the retired legacy FreePBX17 VM. FreePBX17-era references to Phone-LAN gateway `192.168.56.10`, Main-LAN on `enp0s9`, or Phone-LAN on `enp0s8` are stale.
- SeasonalPBX currently uses `enp0s8` for Main-LAN and `enp0s9` for Phone-LAN. `enp0s3` is not the active routing path and has no current IPv4 address in the latest capture.
- The AP has both a Phone-LAN ULA (`FD42:56::4`) and a native Main-LAN-derived global IPv6 address via autoconfiguration.
- The previous capture showed SIP keepalive / OPTIONS / NOTIFY traffic between the PBX and observed phones, plus direct NTP from client devices to upstream servers. Treat exact client leases as live DHCP state.
