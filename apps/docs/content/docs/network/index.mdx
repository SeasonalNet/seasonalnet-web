## Segment Relationships

```text
Internet
    |
Verizon WNC-CR200A (192.168.1.1)
    |
Main LAN (192.168.1.0/24)
    |
    |-- SeasonalEDGE-R1 (192.168.1.4)
    |       |
    |       |-- SeasonalCME Voice VLAN (10.42.0.0/24, VLAN 10)
    |       `-- SeasonalCME Management VLAN (10.42.2.0/24, VLAN 42)
    |
    `-- FreePBX17 (192.168.1.12)
            |
            `-- Phone-LAN (192.168.56.0/24)
```

**Planned addition:** a Dell PowerEdge R230 in the SeasonalCME rack will remain logically on Main LAN by using the existing VLAN 99 transit path, with host `192.168.1.21` and iDRAC `192.168.1.5`, instead of being placed behind SeasonalEDGE-R1 on `10.42.2.0/24`.
