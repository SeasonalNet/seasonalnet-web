| HTTPS | 443 | TCP | SeasonalWeb (`192.168.1.8`) |
| SIP | 5060 | TCP+UDP | SeasonalPBX (`192.168.1.12`) |

| IAX2 | 4569 | UDP | SeasonalPBX (`192.168.1.12`) |

| SMTP | 25 | TCP | SeasonalMail (`192.168.1.13`) |
| Submission | 587 | TCP | SeasonalMail (`192.168.1.13`) |
| SMTPS | 465 | TCP | SeasonalMail (`192.168.1.13`) |
| IMAP | 143 | TCP | SeasonalMail (`192.168.1.13`) |
| POP3 | 110 | TCP | SeasonalMail (`192.168.1.13`) |
| POP3S | 995 | TCP | SeasonalMail (`192.168.1.13`) |

SeasonalWeb performs hostname-based routing for public web services behind the shared 80/443 forwards. `grafana.seasonalnet.org` is routed by SeasonalWeb to Grafana on SeasonalMonitor (`192.168.1.15:3000`) and uses Authentik OAuth/OIDC. Prometheus on SeasonalMonitor (`192.168.1.15:9090`) remains private and is not exposed as a public hostname.

## DNS / DHCP

Cloudflare remains authoritative public DNS for `seasonalnet.org`. SeasonalDNS is for internal LAN recursion/local records only. Current internal aliases include `wx.lan.seasonalnet.org`, `seasonalwx.lan.seasonalnet.org`, and `seasonalweather.lan.seasonalnet.org` for SeasonalWX (`192.168.1.10`), plus `seasonalback.lan.seasonalnet.org` with `back.lan.seasonalnet.org` as a service alias for SeasonalBack (`192.168.1.16`). SeasonalR230 is the primary Proxmox host for the active service VM fleet; SeasonalBack remains hosted on SeasonalR340.

| Segment | DNS | DHCP |
|---|---|---|
| Main LAN | SeasonalDNS / Technitium (`192.168.1.14`) for internal DNS; WNC-CR200A (`192.168.1.1`) remains DHCP/default gateway | Verizon WNC-CR200A |
| SeasonalCME | SeasonalEDGE-R1 (OSPF 42 domain) | SeasonalEDGE-R1 |
| Phone-LAN | `dnsmasq` on SeasonalPBX (`192.168.56.1`, `FD42:56::1`) | `dnsmasq` on SeasonalPBX |
