## Purpose

This section is reserved for public documentation about FOSS projects, reusable services, and deployable systems released from SeasonalNet.

It is intended to grow beyond infrastructure inventory. Future pages may document how to install, operate, customize, or integrate individual SeasonalNet-originated projects in other environments.

## Scope

Appropriate content includes:

- Public setup guides for FOSS projects released from SeasonalNet
- Configuration references that are safe to publish
- API conventions, extension points, and integration notes
- Operational guidance that applies outside the private SeasonalNet deployment
- Project-specific architecture summaries

Inappropriate content includes:

- Private SeasonalNet credentials, tokens, secrets, or host-only access details
- Internal VM runbooks that expose sensitive implementation details
- Deployment steps that only make sense for the private SeasonalNet environment
- Anything that should remain in a project repository but not on the public docs site

## Initial project candidates

No project guide pages are published here yet. SeasonalWeather is a likely future candidate because it is a reusable FOSS-style system with its own setup, customization, API, and deployment concerns.

Other SeasonalNet-originated tools can be added here later when they have public-safe documentation worth publishing.
