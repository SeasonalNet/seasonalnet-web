- **Voice subnet:** `10.42.0.0/24` (VLAN 10)
- **Management subnet:** `10.42.2.0/24` (VLAN 42)
- **Voice IPv6 ULA:** `fd97:418:22dd:10::/64`
- **Management IPv6 ULA:** `fd97:418:22dd:42::/64`
- **Voice gateway:** `10.42.0.1` / `fd97:418:22dd:10::1` (SeasonalEDGE-R1 `Gi0/1`)
- **Management gateway:** `10.42.2.1` / `fd97:418:22dd:42::1` (SeasonalEDGE-R1 `Vlan42`)
- **Last updated:** 2026-06-29

---

## Networks / VLANs

| VLAN / network | Purpose | Gateway | Notes |
|---|---|---|---|
| VLAN 10 / `10.42.0.0/24` | SeasonalCME voice / endpoint IPv4 | `10.42.0.1` | Carries CME router, phones, AP, and voice clients |
| VLAN 10 / `fd97:418:22dd:10::/64` | SeasonalCME voice IPv6 ULA | `fd97:418:22dd:10::1` | RA and stateful DHCPv6 served by SeasonalEDGE-R1 |
| VLAN 42 / `10.42.2.0/24` | SeasonalCME management IPv4 | `10.42.2.1` | Routed through SeasonalEDGE-R1 `Vlan42` |
| VLAN 42 / `fd97:418:22dd:42::/64` | SeasonalCME management IPv6 ULA | `fd97:418:22dd:42::1` | Configured on `Vlan42`; active when the SVI is up |
| VLAN 99 | Main-LAN / transit VLAN | Main-LAN gateway | Native VLAN on SW1↔SW2 trunk; carries rack-local Main-LAN endpoints |

The prior `fd42:42::/64` and `fd42:42:2::/64` prefixes are retired legacy allocations.

## Address Bands

### Voice VLAN 10 (`10.42.0.0/24`)

| Range | Purpose |
|---|---|
| `.1` | Gateway |
| `.2 – .9` | Network infrastructure |
| `.10 – .19` | Core voice infrastructure |
| `.20 – .49` | Reserved static voice devices / important endpoints |
| `.50 – .99` | Static or semi-static lab endpoints |
| `.100 – .254` | DHCP pool / dynamic clients |

Fixed IPv4 assignments include `10.42.0.1` (SeasonalEDGE-R1), `.2` (SW1), `.3` (SW2), `.4` (SeasonalAP-3602i), and `.10` (SeasonalCME-R1).

### Management VLAN 42 (`10.42.2.0/24`)

| Range | Purpose |
|---|---|
| `.1` | Gateway |
| `.2 – .19` | Static management infrastructure |
| `.20 – .49` | Reserved static managed devices |
| `.50 – .99` | Static management expansion |
| `.100 – .254` | Reserved for future DHCP if needed |

VLAN 42 is trunked between the switches, but SeasonalEDGE-R1 `Vlan42` remains down until an active EHWIC VLAN 42 access port is present.

## Routing and Control Plane

| Item | Value | Notes |
|---|---|---|
| IPv4 dynamic routing | OSPFv2 process 42 | FULL adjacency between SeasonalEDGE-R1 and SeasonalCME-R1 |
| IPv6 dynamic routing | OSPFv3 process 42 | FULL adjacency over VLAN 10; EDGE is DR and CME is BDR |
| IPv4 default source | SeasonalEDGE-R1 | `default-information originate` |
| IPv6 default source | SeasonalEDGE-R1 | OSPFv3 external default originated from its Main-LAN static default |
| SeasonalEDGE-R1 IPv4 default | `0.0.0.0/0 via 192.168.1.1` | Upstream CR200A |
| SeasonalEDGE-R1 IPv6 default | `::/0` via CR200A link-local on `Gi0/0` | Native Main-LAN IPv6 upstream |
| CME-R1 learned IPv6 default | OSPFv3 `OE2 ::/0` | Next hop is SeasonalEDGE-R1 link-local on `Gi0/0` |
| CR200A ULA return routes | `:10::/64` and `:42::/64` via SeasonalEDGE-R1 | Primary route metric `10` |
| NAT boundary | SeasonalEDGE-R1 | IPv4 NAT only; `Gi0/0` outside, CME interfaces inside |

OSPFv3 forms its adjacency using link-local addresses.
