- **Voice subnet:** `10.10.0.0/24` (VLAN 10)
- **CME management subnet:** `10.42.0.0/24` (VLAN 42 / CME-MGMT)
- **Voice IPv6 ULA:** `fd97:418:22dd:10::/64`
- **CME management IPv6 ULA:** `fd97:418:22dd:42::/64`
- **Voice gateway:** `10.10.0.1` / `fd97:418:22dd:10::1` (SeasonalNet-DSW1 `Vlan10`)
- **CME management gateway:** `10.42.0.1` / `fd97:418:22dd:42::1` (SeasonalNet-DSW1 `Vlan42`)
- **Last updated:** 2026-09-12

## Networks / VLANs

| VLAN / network | Purpose | Gateway | Notes |
|---|---|---|---|
| VLAN 10 / `10.10.0.0/24` | SeasonalCME voice / endpoint IPv4 | `10.10.0.1` | DSW1 SVI; carries CME-R1 service traffic, phones, AP-3602i service WLAN, and voice clients |
| VLAN 10 / `fd97:418:22dd:10::/64` | SeasonalCME voice IPv6 ULA | `fd97:418:22dd:10::1` | DSW1 SVI and routed IPv6 boundary |
| VLAN 30 / `10.30.0.0/24` | Phone-LAN IPv4 | `10.30.0.1` | DSW1 SVI; distributed primarily through SW3 |
| VLAN 30 / `fd97:418:22dd:30::/64` | Phone-LAN IPv6 ULA | `fd97:418:22dd:30::1` | DSW1 SVI and routed IPv6 boundary |
| VLAN 40 / `10.40.0.0/24` | NET-MGMT IPv4 | `10.40.0.1` | Active general network-device management network |
| VLAN 41 / `10.41.0.0/24` | BMC-MGMT IPv4 | `10.41.0.1` | Active PowerEdge iDRAC management network |
| VLAN 42 / `10.42.0.0/24` | CME-MGMT IPv4 | `10.42.0.1` | CME-specific management; SeasonalCME-R1 management is `.2` |
| VLAN 43 / `10.43.0.0/24` | HOST-MGMT IPv4 | `10.43.0.1` | Routed/reserved for host management |
| VLAN 99 | Main-LAN transit/access VLAN | WNC-CR200A | Layer-2 Main-LAN domain; DSW1 is STP root but not the VLAN 99 IP gateway |
| `10.255.255.0/30` / `fd97:418:22dd:255::/64` | DSW1–FW4C routed transit | Point-to-point | Carries routed traffic and OSPF between distribution and edge |

VLAN 42 is now fully dedicated to `CME-MGMT`; and general network-device management moved to VLAN 40 / `NET-MGMT` on 2026-09-12. The former management subnet `10.42.2.0/24` and legacy `fd42:42::/64` / `fd42:42:2::/64` prefixes were retired when VLAN 10 and the `fd97:418:22dd:` prefix were created. The complete VLAN 40–43 management-family state is documented in [`management-vlans-map.md`](/docs/topology/lans/management-vlans).

## Address Bands

### Voice VLAN 10 (`10.10.0.0/24`)

| Range | Purpose |
|---|---|
| `.1` | DSW1 gateway SVI |
| `.2 – .9` | Network infrastructure and reserved addresses |
| `.10 – .19` | Core voice infrastructure |
| `.20 – .99` | Reserved static voice devices / important endpoints |
| `.100 – .254` | DHCP pool / dynamic clients |

Fixed assignments include `10.10.0.1` (SeasonalNet-DSW1) and `10.10.0.10` (SeasonalCME-R1 service identity). SeasonalAP-3602i participates in Voice VLAN 10 as a service bridge, but its management BVI is on NET-MGMT rather than VLAN 10.

### CME-MGMT VLAN 42 (`10.42.0.0/24`)

| Range | Purpose |
|---|---|
| `.1` | DSW1 routed gateway |
| `.2` | SeasonalCME-R1 management identity |
| `.3 – .99` | Reserved static CME-management infrastructure / expansion |
| `.100 – .254` | Reserved for future use |

CME-MGMT VLAN 42 uses static infrastructure addressing, and general switch/AP management moved to NET-MGMT/VLAN 40. Neither of those VLANs provide DHCPv4/v6 client pools.

## Distribution, Switching, and Uplinks

| Device | Role | Key uplink(s) | Notes |
|---|---|---|---|
| SeasonalNet-DSW1 (`WS-C3850-12S`) | Layer-3 distribution core and STP root | `Gi1/0/1` routed to FW4C; `Po1` to ASW1; `Gi1/0/10` to SW3 | Owns all VLAN SVIs, except 99, and performs inter-VLAN routing (with the exception of 99), is the Rapid-PVST root for **all** VLANs, and has the IGMP querier role |
| SeasonalNet-ASW1 (`WS-C3850-48P`) | Primary PoE+ access/aggregation switch | `Po1` (`Gi1/1/1-2`) to DSW1; `Gi1/0/3` to SW3 | Aggregates CME, AP, server/BMC, Main-LAN, and general access attachments |
| SeasonalNet-SW3 (`WS-C2960CX-8PC-L`) | Compact PoE Phone-LAN/access switch | Fiber `Gi0/11` to DSW1; redundant `Gi0/10` trunk to ASW1 | Distributes Phone-LAN and provides AP-2702E attachment |
| FW4C (`Protectli FW4C-RR`) | Production edge firewall/router | Main-LAN outside at `192.168.1.5`; inside transit to DSW1 | Owns upstream firewall/NAT boundary and exchanges routes with DSW1 |
| SeasonalCME-R1 (`2901-CME-SRST`) | CME router / UC node | ASW1 `Gi1/0/5` trunk to `Gi0/0` | Voice service on native VLAN 10; CME management tagged on VLAN 42; not a default gateway |
| SeasonalNet-NP-R1 (`1921/K9`) | Non-production lab router | Main-LAN management at `192.168.1.54` | Former SeasonalEDGE-R1; removed from production VLAN routing, NAT, DHCP, and OSPF |

The DSW1/ASW1 LACP trunk carries all production access VLANs, except 98. SW3 has a direct fiber trunk to DSW1 and a redundant trunk to ASW1.

## Routing and Control Plane

| Item | Value | Notes |
|---|---|---|
| Inter-VLAN routing | SeasonalNet-DSW1 | Routes between VLANs 10, 30, 40, 41, 42, and 43 |
| Upstream routed transit | `10.255.255.0/30` / `fd97:418:22dd:255::/64` | DSW1 `.1` / `::1`; FW4C `.2` / `::2` |
| DSW1 ↔ FW4C IPv4 routing | OSPFv2, FULL point-to-point adjacency | FW4C neighbor `10.255.255.2` on DSW1 `Gi1/0/1` |
| DSW1 ↔ CME-R1 IPv4 routing | OSPFv2, FULL broadcast adjacency | CME-R1 `Gi0/0.10` / `10.10.0.10` is the Voice VLAN 10 adjacency |
| IPv6 dynamic routing | OSPFv3 | Runs on the corresponding DSW1–FW4C transit and DSW1–CME Voice VLAN 10 path |
| Routed default source | FW4C | DSW1 sends Internet/default traffic across the transit to FW4C |
| CR200A IPv4 return routes | VLANs 10, 30, 40, 41, 42, and 43 via `192.168.1.5` | FW4C is the Main-LAN next hop; metric `10` |
| NAT boundary | FW4C | IPv4 Internet NAT/firewall boundary; DSW1 does not NAT |
| Legacy EDGE role | Removed | NP-R1 has no production NAT, DHCP, OSPF, or VLAN gateway configuration |
