- **Voice subnet:** `10.10.0.0/24` (VLAN 10)
- **Management subnet:** `10.42.0.0/24` (VLAN 42)
- **Voice IPv6 ULA:** `fd97:418:22dd:10::/64`
- **Management IPv6 ULA:** `fd97:418:22dd:42::/64`
- **Voice gateway:** `10.10.0.1` / `fd97:418:22dd:10::1` (SeasonalEDGE-R1 `Gi0/1`)
- **Management gateway:** `10.42.0.1` / `fd97:418:22dd:42::1` (SeasonalEDGE-R1 `Gi0/1.42`)
- **Last updated:** 2026-07-02

---

## Networks / VLANs

| VLAN / network | Purpose | Gateway | Notes |
|---|---|---|---|
| VLAN 10 / `10.10.0.0/24` | SeasonalCME voice / endpoint IPv4 | `10.10.0.1` | Carries CME-R1, phones, the AP, and voice clients |
| VLAN 10 / `fd97:418:22dd:10::/64` | SeasonalCME voice IPv6 ULA | `fd97:418:22dd:10::1` | RA and stateful DHCPv6 served by SeasonalEDGE-R1 |
| VLAN 42 / `10.42.0.0/24` | SeasonalCME infrastructure management IPv4 | `10.42.0.1` | Tagged subinterface on SeasonalEDGE-R1 `Gi0/1.42` |
| VLAN 42 / `fd97:418:22dd:42::/64` | SeasonalCME infrastructure management IPv6 ULA | `fd97:418:22dd:42::1` | RA served by SeasonalEDGE-R1; static infrastructure assignments where supported |
| VLAN 99 | Main-LAN / transit VLAN | Main-LAN gateway | Native VLAN on the SW1↔SW2 trunk; carries rack-local Main-LAN endpoints |

The former Voice VLAN 10 IPv4 subnet `10.42.0.0/24` was moved to Management VLAN 42, and Voice VLAN 10 was renumbered to `10.10.0.0/24`. The former management subnet `10.42.2.0/24` and legacy `fd42:42::/64` / `fd42:42:2::/64` prefixes are retired.

## Address Bands

### Voice VLAN 10 (`10.10.0.0/24`)

| Range | Purpose |
|---|---|
| `.1` | Gateway |
| `.2 – .9` | Network infrastructure and reserved addresses |
| `.10 – .19` | Core voice infrastructure |
| `.20 – .99` | Reserved static voice devices / important endpoints |
| `.100 – .254` | DHCP pool / dynamic clients |

Fixed assignments include `10.10.0.1` (SeasonalEDGE-R1), `10.10.0.4` (SeasonalAP-3602i), and `10.10.0.10` (SeasonalCME-R1). `10.10.0.2` is reserved as the SW1 IGMP snooping querier source address.

### Management VLAN 42 (`10.42.0.0/24`)

| Range | Purpose |
|---|---|
| `.1` | Gateway |
| `.2 – .19` | Static management infrastructure |
| `.20 – .99` | Reserved static managed devices / expansion |
| `.100 – .254` | Reserved for future use |

Management VLAN 42 uses static infrastructure addressing. It does not currently provide a DHCPv4 pool.

SeasonalNet-SW1 is a `WS-C2960X-24TS-LL` LAN Lite chassis. It can bridge IPv6 and communicate with on-link IPv6 neighbors, but it does not provide usable off-link IPv6 management in this deployment, so its routed management address is IPv4-only. SeasonalNet-SW2 is a LAN Base chassis and remains dual-stack on VLAN 42.

## Switch Roles and Uplinks

| Device | Role | Key uplink(s) | Notes |
|---|---|---|---|
| SeasonalNet-SW1 | Root / aggregation switch | `Gi0/23` trunk to SW2; `Gi0/24` trunk to EDGE-R1 | Verified root bridge for VLANs 10 and 42; primary rack switch |
| SeasonalNet-SW2 | Secondary / access PoE switch | `Gi1/0/24` trunk to SW1 | Uses SW1 as its root path for VLANs 10 and 42 |
| SeasonalEDGE-R1 | Lab edge router | `Gi0/0` to Main LAN; `Gi0/1` trunk to SW1 `Gi0/24` | Terminates Voice VLAN 10 natively and Management VLAN 42 on a tagged subinterface |
| SeasonalCME-R1 | CME router / UC node | `Gi0/0` to SW1 `Gi0/21` | Dual-stack on Voice VLAN 10 |

## Routing and Control Plane

| Item | Value | Notes |
|---|---|---|
| IPv4 dynamic routing | OSPFv2 process 42 | FULL adjacency between SeasonalEDGE-R1 and SeasonalCME-R1 over Voice VLAN 10 |
| OSPFv2 router IDs | EDGE `10.10.0.1`; CME `10.10.0.10` | EDGE interface priority `255` and DR; CME priority `0` and DROTHER |
| IPv6 dynamic routing | OSPFv3 process 42 | FULL adjacency over Voice VLAN 10 using link-local next hops |
| IPv4 default source | SeasonalEDGE-R1 | `default-information originate` toward SeasonalCME-R1 |
| IPv6 default source | SeasonalEDGE-R1 | OSPFv3 external default originated from its Main-LAN IPv6 default |
| SeasonalEDGE-R1 IPv4 default | `0.0.0.0/0 via 192.168.1.1` | Upstream CR200A |
| SeasonalEDGE-R1 IPv6 default | `::/0` via CR200A link-local on `Gi0/0` | Native Main-LAN IPv6 upstream |
| CR200A IPv4 return routes | `10.10.0.0/24` and `10.42.0.0/24` via `192.168.1.4` | Primary route metric `10` |
| CR200A ULA return routes | `:10::/64` and `:42::/64` via SeasonalEDGE-R1 | Primary route metric `10` |
| NAT boundary | SeasonalEDGE-R1 | IPv4 NAT only; `Gi0/0` outside, `Gi0/1` and `Gi0/1.42` inside |

The `NAT_INSIDE` policy bypasses translation for traffic from either SeasonalCME IPv4 subnet to Main LAN (`192.168.1.0/24`) and SeasonalVPN (`10.88.0.0/24`). Other matching IPv4 traffic is overloaded through SeasonalEDGE-R1 `Gi0/0`.

## Address Assignment

| Segment / device | Method | Notes |
|---|---|---|
| Voice VLAN 10 IPv4 | DHCPv4 | SeasonalEDGE-R1 serves `.100 – .254`; gateway `.1`, option 150 `.10`, and NTP option 42 `.1` |
| Voice VLAN 10 IPv6 | RA + stateful DHCPv6 | SeasonalEDGE-R1 advertises the `/64` and serves DHCPv6 IA_NA addresses |
| Management VLAN 42 IPv4 | Static | Gateway and switch management addresses are configured on-device |
| Management VLAN 42 IPv6 | RA + static infrastructure addresses | EDGE-R1 advertises the prefix; SW2 is static; SW1 is IPv4-only for routed management |
| SeasonalCME-R1 | Static dual-stack | `10.10.0.10` and `fd97:418:22dd:10::10/64` |
| SeasonalAP-3602i | Static IPv4 + dynamic IPv6 | `10.10.0.4`; SLAAC/DHCPv6 client behavior |
| Phones / lab clients | DHCPv4 and IPv6 by device capability | Voice clients use the VLAN 10 services |

## Known Limitations / Remaining Items

- SeasonalNet-SW1 remains IPv4-only for routed management because its LAN Lite feature set does not install a usable off-link IPv6 default-router state in this deployment.
- Keep the disabled Aironet and powerline paths documented as retired/quarantined unless deliberately restored.
