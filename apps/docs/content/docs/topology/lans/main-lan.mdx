## Static Routing on WNC-CR200A

Primary static routes use metric `10`; future alternate or backup routes use metric `50` or higher.

| Destination | Next hop | Metric | Notes |
|---|---|---:|---|
| `10.10.0.0/24` | `192.168.1.5` | `10` | SeasonalCME Voice IPv4 return route through FW4C |
| `10.30.0.0/24` | `192.168.1.5` | `10` | Phone-LAN IPv4 return route through FW4C |
| `10.42.0.0/24` | `192.168.1.5` | `10` | SeasonalCME Management IPv4 return route through FW4C |
| `10.88.0.0/24` | `192.168.1.22` | `10` | SeasonalVPN IPv4 return route |
| `fd97:418:22dd:10::/64` | FW4C Main-LAN link-local | `10` | SeasonalCME Voice ULA return route |
| `fd97:418:22dd:30::/64` | FW4C Main-LAN link-local | `10` | Phone-LAN ULA return route |
| `fd97:418:22dd:42::/64` | FW4C Main-LAN link-local | `10` | SeasonalCME Management ULA return route |
| `fd97:418:22dd:88::/64` | SeasonalVPN Main-LAN link-local | `10` | SeasonalVPN ULA return route |

The Main LAN itself uses the CR200A's native ISP-assigned IPv6 prefix. The SeasonalNet ULA `/48` is routed only as specific `/64`s because different segments have different next hops.

FW4C owns the production edge/firewall role at `192.168.1.5`. SeasonalNet-DSW1 reaches it over `10.255.255.0/30` and `fd97:418:22dd:255::/64`, then routes VLANs 10, 30, and 42 through FW4C for upstream access. SeasonalNet-NP-R1 at `192.168.1.54` is not part of this path; it retains only Main-LAN management, independent IPv4/IPv6 defaults through the CR200A, and fully suppressed outbound IPv6 Router Advertisements.

## Known Remaining Items

- SeasonalBack currently stores PBS data on its VM root filesystem / single virtual disk. Re-document if a separate datastore disk, passthrough disk, direct-attached storage layout, or SeasonalNAS-backed backup storage layout is added.
- SeasonalMonitor SNMP polling and Redfish/iDRAC collection have a working foundation; continue expanding dashboards and target coverage as needed.
- SeasonalBridge-NONROOT remains quarantined/disabled as a production path; clean up stale bridge IPv6/autoconfig details only if the Aironet bridge is revisited.
- During the 2026-06-07 LAN reshuffle, live `systemctl restart networking` on the Proxmox hosts detached VM tap interfaces from `vmbr0`; avoid that operation on live VM hosts unless prepared to reattach taps or reboot during maintenance.
