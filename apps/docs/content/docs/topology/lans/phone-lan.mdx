## Notes and Constraints

- Phone-LAN has been readdressed from `192.168.56.0/24` to `10.30.0.0/24`, and from `fd42:56::/64` to `fd42:30::/64`.
- SeasonalPBX replaces the retired legacy FreePBX17 VM as the active PBX service, but it no longer routes Phone-LAN. FreePBX17-era and PBX-router references to `192.168.56.1`, `192.168.56.10`, `fd42:56::1`, Main-LAN on `enp0s9`, Phone-LAN on `enp0s8`, PBX `dnsmasq`, or PBX NAT/masquerade are stale.
- Phone-LAN is currently documented as a readdressed segment with a pending managed-switch/trunk migration. Do not invent final Catalyst port mappings or gateway ownership until captured from the installed configuration.
- Native global IPv6/SLAAC addresses should be treated as live state rather than stable public documentation identity.
- Treat exact phone/ATA client leases as live DHCP state.
