## Routing / Services Boundary

| Item | Value | Notes |
|---|---|---|
| Phone-LAN router | Not SeasonalPBX | Gateway ownership remains pending the managed-switch/trunk migration |
| Gateway reservation | `10.30.0.1` / `fd97:418:22dd:30::1` | Reserved for the future routed boundary |
| Current physical switching | TP-Link TL-SF1005P, hardware label `UN/5.6` / likely V5.60 | Temporary unmanaged 10/100 PoE+ switch with no management address or querier role |
| Planned physical switching | Cisco Catalyst C2960CX or C3560CX | Planned compact managed replacement with an Ethernet uplink to the rack |
| PBX service | SeasonalPBX (`192.168.1.12`) | Phones reach it as a routed service endpoint after the gateway is implemented |
| DHCPv4 service | Pending | Previous SeasonalPBX `dnsmasq` router model is retired |
| IPv6 RA / DHCPv6 service | Pending | Future gateway will advertise `fd97:418:22dd:30::/64` |
| IPv4 NAT | Not on SeasonalPBX | Phone-LAN is intended to be routed, not hidden behind the PBX VM |

The unmanaged switch may flood IPv6 multicast to all forwarding ports because MLD snooping is not documented. This is acceptable for the small temporary segment and does not prevent IPv6 operation.

## Notes and Constraints

- Phone-LAN has moved from `192.168.56.0/24` / `fd42:56::/64` to `10.30.0.0/24` / `fd97:418:22dd:30::/64`.
- SeasonalPBX remains the active PBX service but no longer routes Phone-LAN.
- Same-link IPv6 reachability to SeasonalAP-2702E was verified directly before returning the maintenance host to IPv4 link-local state.
- Main-LAN native GUA addresses are live ISP state and are not stable Phone-LAN identity.
