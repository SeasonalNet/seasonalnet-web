## SeasonalNet ULA Allocation

SeasonalNet uses one randomly generated site ULA allocation:

```text
fd97:418:22dd::/48
```

The fourth hextet is the 16-bit subnet identifier. SeasonalNet writes that identifier as the human-readable VLAN or functional segment number rather than converting the printed decimal label to hexadecimal.

| Segment ID | Prefix | Assignment |
|---:|---|---|
| `10` | `fd97:418:22dd:10::/64` | SeasonalCME Voice / VLAN 10 |
| `30` | `fd97:418:22dd:30::/64` | Phone-LAN / VLAN 30 |
| `40` | `fd97:418:22dd:40::/64` | NET-MGMT / VLAN 40 |
| `41` | `fd97:418:22dd:41::/64` | BMC-MGMT / VLAN 41 |
| `42` | `fd97:418:22dd:42::/64` | CME-MGMT / VLAN 42 |
| `43` | `fd97:418:22dd:43::/64` | HOST-MGMT / VLAN 43 |
| `88` | `fd97:418:22dd:88::/64` | SeasonalVPN routed VPN LAN |
| `255` | `fd97:418:22dd:255::/64` | DSW1–FW4C routed transit |

Rules:

- Each ordinary LAN receives a `/64`.
- `::1` is reserved for the segment router/gateway.
- Main LAN remains native ISP IPv6 and does not consume a ULA `/64`.
- Do not route the complete `/48` through one next hop while different `/64`s are owned by different routers.

## Routing

### Distribution and edge routing

SeasonalNet-DSW1 is the Layer-3 distribution core for VLANs 10, 30, 40, 41, 42, and 43. It owns the IPv4 and IPv6 SVI gateway addresses and performs inter-VLAN routing. VLAN 99 remains the Main-LAN Layer-2 domain and continues to use the WNC-CR200A as its gateway.

FW4C is the production edge firewall/router between DSW1 and Main LAN. The routed transit is:

| Endpoint | IPv4 | IPv6 | Interface relationship |
|---|---|---|---|
| SeasonalNet-DSW1 | `10.255.255.1/30` | `fd97:418:22dd:255::1/64` | `Gi1/0/1` toward FW4C |
| FW4C | `10.255.255.2/30` | `fd97:418:22dd:255::2/64` | Inside interface toward DSW1 |
| FW4C Main-LAN side | `192.168.1.5/24` | Native Main-LAN IPv6 | Upstream toward WNC-CR200A |

Internet-bound traffic from the routed VLANs is sent from DSW1 across the transit to FW4C. FW4C owns the IPv4 NAT/firewall boundary; DSW1 does not perform Internet NAT.

The VLAN 40–43 management family is documented in [`LANs/management-vlans-map.md`](/docs/topology/lans/management-vlans). VLAN 41 is already active for the PowerEdge BMCs. General switch/network-device management remains temporarily on VLAN 42 and is scheduled to move to VLAN 40; VLAN 43 is routed but has no production host-management cutover yet.

### Dynamic routing

OSPF is used on the routed control-plane links:

| Adjacency | IPv4 relationship | IPv6 relationship | Notes |
|---|---|---|---|
| DSW1 ↔ FW4C | Point-to-point over `10.255.255.0/30` | OSPFv3 over the corresponding IPv6 transit | DSW1 learns the upstream/default path from FW4C |
| DSW1 ↔ SeasonalCME-R1 | Broadcast adjacency on Voice VLAN 10 | OSPFv3 on Voice VLAN 10 | CME-R1 uses priority `0` and remains DROTHER; DSW1 owns the VLAN gateway |

OSPF process IDs are locally significant and do not need to match between devices.

### Layer-2 control plane

SeasonalNet-DSW1 is the Rapid-PVST root for VLANs 10, 30, 40, 41, 42, 43, and 99. The direct DSW1 fiber uplinks remain the preferred root paths; the retained SW1–SW2 and SW2–SW3 copper trunks remain physically connected as redundant paths and are normally held out of the forwarding topology by Rapid-PVST where appropriate. DSW1 continues to own the active IGMP snooping querier role for the routed VLANs where configured.

## DNS / DHCP

Cloudflare remains authoritative public DNS for `seasonalnet.org`. SeasonalDNS provides internal recursion and `lan.seasonalnet.org` records. SeasonalVPN uses `seasonalvpn.lan.seasonalnet.org` with `vpn.lan.seasonalnet.org` as an internal alias at `192.168.1.22`.

| Segment | DNS | DHCP / address assignment |
|---|---|---|
| Main LAN | SeasonalDNS (`192.168.1.14`) for internal DNS | WNC-CR200A for IPv4 DHCP and native IPv6 RA/DHCPv6 |
| SeasonalCME Voice VLAN 10 | SeasonalDNS plus voice-specific options | SeasonalNet-DSW1 owns the IPv4 gateway and DHCPv4 boundary; CME-R1 remains static at `.10` |
| Phone-LAN VLAN 30 | SeasonalDNS (`192.168.1.14`) | SeasonalNet-DSW1 owns the routed gateway and current DHCPv4 boundary |
| NET-MGMT VLAN 40 | SeasonalDNS for managed infrastructure | Static infrastructure addressing; routed and staged for the network-device migration from VLAN 42 |
| BMC-MGMT VLAN 41 | SeasonalDNS for BMC FQDNs | Static IPv4 BMC assignments; DSW1 owns the dual-stack gateway SVI while iDRAC IPv6 remains disabled |
| CME-MGMT VLAN 42 | SeasonalDNS for managed infrastructure | Static infrastructure addressing; still carries transitional switch-management identities pending VLAN 40 cutover |
| HOST-MGMT VLAN 43 | SeasonalDNS when host identities are assigned | Routed/reserved; no production host-management cutover yet |
| SeasonalVPN | Routed through SeasonalVPN/Defguard policy | Defguard assigns VPN client addresses |

IPv6 gateway ownership for VLANs 10, 30, 40, 41, 42, and 43 is on DSW1. Exact client RA/DHCPv6 behavior follows the live DSW1 configuration and device capability.

Admin/static hosts should prefer SeasonalDNS directly for internal DNS.

## Proxmox Bridge Cutover Note

During the 2026-06-07 LAN reshuffle, restarting networking on live Proxmox hosts detached VM tap interfaces from `vmbr0`. Host management remained reachable, but guests were isolated until their tap interfaces were reattached. Avoid live `systemctl restart networking` on Proxmox hosts unless prepared to repair bridge membership or reboot during maintenance.
