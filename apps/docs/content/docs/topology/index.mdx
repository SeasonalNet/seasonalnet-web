## SeasonalNet ULA Allocation

SeasonalNet uses one randomly generated site ULA allocation:

```text
fd97:418:22dd::/48
```

The fourth hextet is the 16-bit subnet identifier. SeasonalNet writes that identifier as the human-readable VLAN or functional segment number rather than converting the printed decimal label to hexadecimal.

| Segment ID | Prefix | Assignment |
|---:|---|---|
| `10` | `fd97:418:22dd:10::/64` | SeasonalCME Voice / VLAN 10 |
| `30` | `fd97:418:22dd:30::/64` | Phone-LAN / planned VLAN 30 |
| `42` | `fd97:418:22dd:42::/64` | SeasonalCME Management / VLAN 42 |
| `88` | `fd97:418:22dd:88::/64` | SeasonalVPN routed VPN LAN |

Rules:

- Each ordinary LAN receives a `/64`.
- `::1` is reserved for the segment router/gateway.
- Main LAN remains native ISP IPv6 and does not consume a ULA `/64`.
- Do not route the complete `/48` through one next hop while different `/64`s are owned by different routers.

## Routing

### Dynamic routing

SeasonalEDGE-R1 and SeasonalCME-R1 use process ID `42` for both protocol families:

| Protocol | Address family | Purpose |
|---|---|---|
| OSPFv2 process 42 | IPv4 | Routes the SeasonalCME IPv4 domain and originates the IPv4 default from SeasonalEDGE-R1 |
| OSPFv3 process 42 | IPv6 | Forms a FULL adjacency over Voice VLAN 10 and originates the IPv6 default from SeasonalEDGE-R1 |

SeasonalCME-R1 has `fd97:418:22dd:10::10/64` on `Gi0/0` and learns `::/0` through OSPFv3. SeasonalEDGE-R1 terminates Management VLAN 42 on `Gi0/1.42` and advertises it into OSPFv2 and OSPFv3.

### WNC-CR200A static routes

Primary static routes use metric `10`. Future alternate or backup routes use metric `50` or higher.

| Destination | Next hop | Metric | Purpose |
|---|---|---:|---|
| `10.10.0.0/24` | `192.168.1.4` | `10` | SeasonalCME Voice IPv4 return route |
| `10.42.0.0/24` | `192.168.1.4` | `10` | SeasonalCME Management IPv4 return route |
| `10.88.0.0/24` | `192.168.1.22` | `10` | SeasonalVPN IPv4 return route |
| `fd97:418:22dd:10::/64` | SeasonalEDGE-R1 `Gi0/0` link-local | `10` | SeasonalCME Voice ULA return route |
| `fd97:418:22dd:42::/64` | SeasonalEDGE-R1 `Gi0/0` link-local | `10` | SeasonalCME Management ULA return route |
| `fd97:418:22dd:88::/64` | SeasonalVPN Main-LAN link-local | `10` | SeasonalVPN ULA return route |

The Phone-LAN `/64` will receive a return route after its gateway owner is implemented.

## DNS / DHCP

Cloudflare remains authoritative public DNS for `seasonalnet.org`. SeasonalDNS provides internal recursion and `lan.seasonalnet.org` records. SeasonalVPN uses `seasonalvpn.lan.seasonalnet.org` with `vpn.lan.seasonalnet.org` as an internal alias at `192.168.1.22`.

| Segment | DNS | DHCP / address assignment |
|---|---|---|
| Main LAN | SeasonalDNS (`192.168.1.14`) for internal DNS | WNC-CR200A for IPv4 DHCP and native IPv6 RA/DHCPv6 |
| SeasonalCME | SeasonalEDGE-R1 supplies Voice VLAN 10 DHCPv4/DHCPv6; clients use configured resolvers | Voice VLAN 10 uses EDGE-R1 DHCP; Management VLAN 42 uses static IPv4 and RA/static IPv6 |
| SeasonalVPN | Routed through SeasonalVPN/Defguard policy | Defguard assigns VPN client addresses |
| Phone-LAN | Owner pending managed-switch/trunk implementation | DHCPv4 and IPv6 RA/DHCPv6 owner pending |

Admin/static hosts should prefer SeasonalDNS directly for internal DNS.

## Proxmox Bridge Cutover Note

During the 2026-06-07 LAN reshuffle, restarting networking on live Proxmox hosts detached VM tap interfaces from `vmbr0`. Host management remained reachable, but guests were isolated until their tap interfaces were reattached. Avoid live `systemctl restart networking` on Proxmox hosts unless prepared to repair bridge membership or reboot during maintenance.
