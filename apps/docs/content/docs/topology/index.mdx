## DNS / DHCP

Cloudflare remains authoritative public DNS for `seasonalnet.org`. SeasonalDNS is for internal LAN recursion/local records only. Current internal aliases include `wx.lan.seasonalnet.org`, `seasonalwx.lan.seasonalnet.org`, and `seasonalweather.lan.seasonalnet.org` for SeasonalWX (`192.168.1.10`), plus `seasonalback.lan.seasonalnet.org` with `back.lan.seasonalnet.org` as a service alias for SeasonalBack (`192.168.1.16`). SeasonalNAS uses `seasonalnas.lan.seasonalnet.org` (`192.168.1.17`), SeasonalSand uses `seasonalsand.lan.seasonalnet.org` (`192.168.1.18`), SeasonalDB uses `seasonaldb.lan.seasonalnet.org` (`192.168.1.19`), and SeasonalDock uses `seasonaldock.lan.seasonalnet.org` (`192.168.1.20`). SeasonalR230 and SeasonalR340 moved to the hypervisor/BMC band at `.30` and `.31` respectively. SeasonalCA uses `seasonalca.lan.seasonalnet.org` and `ca.lan.seasonalnet.org` at `192.168.1.21`.

| Segment | DNS | DHCP |
|---|---|---|
| Main LAN | SeasonalDNS / Technitium (`192.168.1.14`) for internal DNS; WNC-CR200A (`192.168.1.1`) remains DHCP/default gateway | Verizon WNC-CR200A |
| SeasonalCME | SeasonalEDGE-R1 (OSPF 42 domain) | SeasonalEDGE-R1 |
| Phone-LAN | DNS/DHCP owner TBD after PBX-router removal; clients should reach SeasonalPBX as routed service at `192.168.1.12` | DHCP owner TBD; previous PBX `dnsmasq` model retired |

Admin/static hosts should prefer SeasonalDNS (`192.168.1.14`) directly for DNS to avoid router-side stale or empty local answers for `lan.seasonalnet.org` records.

## Proxmox Bridge Cutover Note

During the 2026-06-07 LAN reshuffle, restarting networking on live Proxmox hosts detached VM tap interfaces from `vmbr0`. The host management addresses remained reachable, but the guest VMs could not reach the LAN until the tap interfaces were reattached.

Avoid `systemctl restart networking` on Proxmox hosts while VMs are live. Prefer a maintenance reboot or use `ifreload -a` where appropriate. If tap interfaces detach, reattach them carefully:

```bash
for dev in /sys/class/net/tap*; do
  dev="${dev##*/}"
  ip link set "$dev" master vmbr0
  ip link set "$dev" up
done
```
