Static reference documentation for the SeasonalNet homelab infrastructure. The repository is maintained as the public-safe documentation source for the rendered docs site.

---

## Structure

```
SeasonalNet-Documentation/
├── README.md          # This file
├── AGENTS.md          # Agent/machine reference for this documentation set
├── NETWORK.md         # Top-level network overview and segment index
└── LANs/
    ├── seasonalnet-lan-map.md     # Main LAN (192.168.1.0/24) — top-level segment
    ├── seasonalcme-network-map.md # SeasonalCME lab (10.42.0.0/24, 10.42.2.0/24)
    └── phonelan-map.md            # Phone-LAN (192.168.56.0/24)
```

> `VMs/` exists locally but is excluded from any repository or published documentation. It contains host-level credentials and per-VM configuration detail that must not be committed or shared.

---

## Scope

This documentation covers:

- Layer 2 / Layer 3 topology for all SeasonalNet network segments
- Device inventory, static address assignments, and address band purpose
- Routing, NAT, and services boundaries
- Physical switch port maps where applicable
- Known gaps and deferred cleanup items

It does **not** cover:

- VM-level configuration or credentials (`VMs/` — local only)
- Application-layer configuration for hosted services
- SeasonalWeather, SeasonalPBX, or SeasonalWeb internal architecture (maintained separately in their respective repositories)

---

## Publication

This documentation is published through the SeasonalWeb / SeasonalNet Next.js docs deployment at `docs.seasonalnet.org`. The rendered site must continue to conform to the uniform SeasonalNet SPA design: shared header/footer and black-and-white theming.

`VMs/` remains local-only and must stay excluded from the repository and from the published documentation source.
