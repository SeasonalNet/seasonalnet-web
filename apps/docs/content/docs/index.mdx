## Publication scope

This documentation may cover:

- Platform identity, public-safe service inventory, and subsystem boundaries
- Layer 2 / Layer 3 topology for SeasonalNet network segments
- Device inventory, static address assignments, and address band purpose
- Routing, NAT, and services boundaries
- Physical switch port maps where applicable
- Public FOSS project reference material and deployment/customization guides
- Platform-wide privacy, terms-of-service, and acceptable-use policies
- Known gaps and deferred cleanup items when they are public-safe

It does **not** cover:

- VM-level credentials or sensitive configuration (`VMs/` — local only)
- Secrets, private tokens, internal-only operational material, or unpublished access details
- Live runtime truth that should be read from monitoring, admin, or agent tooling instead

---

## Publication

This documentation is published through the SeasonalWeb / SeasonalNet Next.js docs deployment at `docs.seasonalnet.org`. The rendered site must continue to conform to the uniform SeasonalNet SPA design: shared header/footer and black-and-white theming.

`VMs/` remains local-only and must stay excluded from the repository and from the published documentation source.
